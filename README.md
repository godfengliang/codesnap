# CodeSnap — Beautiful Code Screenshots

Turn your code into beautiful, shareable screenshots. Like Carbon but simpler, faster, and works offline.

**Live Demo:** [codesnap-tool.surge.sh](https://codesnap-tool.surge.sh/)

## Features

- **Syntax highlighting** — 12 languages with token-based coloring
- **6 editor themes** — Monokai, GitHub Dark, Dracula, Solarized, Nord, One Dark
- **6 backgrounds** — Gradient and solid backgrounds
- **Window chrome** — macOS-style title bar with traffic lights
- **Line numbers** — Automatic line numbering
- **Tab support** — Press Tab in the editor to indent
- **Export PNG** — High-resolution 2x export
- **Zero dependencies** — Single HTML file, works offline

## Tech

- Pure HTML/CSS/JavaScript — no build step, no npm, no frameworks
- Canvas API for rendering (no html2canvas)
- Custom tokenizer for syntax highlighting
- Responsive split-pane editor + live preview
